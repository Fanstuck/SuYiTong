# 作品简介（500 字以内）

**作品名称：** 速易通（SuYiTong）  
**所选赛题：** Agent 方向——科研短论文全流程/半流程自动化生成

速易通是面向高校学生、青年科研人员和研发团队的可追溯科研 Agent 中台，解决科研写作中流程割裂、文献与论点脱节、多智能体交接丢失依据、实验结果难复现等问题。平台基于 JiuwenSwarm 和第三方模型 API，将选题拆解、OpenAlex/Crossref 文献调研、方法设计、实验协议、论文写作与质量门串成可审批流程。核心创新 PACM-SW 以约束、程序、情节、语义四层记忆组织上下文，结合语义、词法、溯源、角色、图关系、时效、冲突和冗余信号，在有限 Token 预算下选择可信证据，并以 PAPER 编号、JSONL、SHA-256 和人工质量门保留完整证据链。当前原型已完成选题至实验阶段的可运行链路、B2/B3/PACM-SW 真实检索、R1-R6 消融调度及 B0/B1 生成框架；模块化接口、示例配置和复现实验记录便于科研团队复用与扩展。
