## 当前提交口径

- 项目定位：基于 JiuwenSwarm 的可追溯科研 Agent 中台。
- 核心方法：PACM-SW（Provenance-Aware Context Memory for Scientific Writing，工作名）。
- 当前范围：本地 Web + FastAPI + JiuwenSwarm，第三方模型 API，无需本地 GPU。
- 已完成：选题、文献调研、方法设计、实验协议、真实检索、盲化 qrels、消融与 B0/B1 调度框架。
- 未完成：正式人工 qrels、完整正式生成矩阵、统计审计、ICLR 论文最终交付。
- HarmonyOS：仅作为未来多端扩展方向，不作为当前已实现能力。
