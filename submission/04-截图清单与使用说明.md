## 三、截图来源说明

- `01、02、06–10`：2026-08-16 从当前运行版本自动截取。
- `03–05`：对应选题、文献和方法阶段完成时保存的真实产品运行截图；当前项目已进入实验阶段，页面会折叠已确认产物，因此沿用阶段存档。

## 四、使用安全规则

- 环境配置截图不得出现 API Key、OpenAlex Key、Embedding Key 或自定义认证 Header。
- 不公开浏览器开发者工具、网络请求详情、SQLite 数据库、完整 JSONL 正文和本地用户名路径。
- PPT 中引用长图时只裁取叙事相关区域，字体需保持可读；不要把整张长图缩成一条细线。
- Demo 中可展示 JSONL 的记录数与 SHA-256，但不要展开可能含研究输入的日志内容。
